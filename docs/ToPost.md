# 2026-08-26 작업 내용 — 야외에 나갔고, 두 가지가 걸렸다

2.1의 마지막 남은 일이 "낮에 30분 걸어보기"였다. 나갔다 왔는데 **계획대로 되지 않았다.**

| | 목표 | 실제 |
|---|---|---|
| 걸은 시간 | 30분 이상 | **21.2분** (중간에 한 번 끊김) |
| 밝기 | 낮 | **해질녘** (평균 밝기 47 → 8/4 낮은 107) |
| 얻은 것 | 색 보정 검증, 경보 빈도 실측 | 둘 다 얻음 ✅ |
| 예상 못 한 것 | — | **전원이 나감**, **거리 센서가 6cm를 봄** |

---

## 걸린 것 1 — 걷는 중에 전원이 나갔다

첫 세션이 18:49:27에 뚝 끊겼다. 마지막 줄까지 값은 완전히 정상이었다(온도 40.7도, 거리 292cm). 그 다음이 없다.

기록을 보면 이렇다.

| 확인한 것 | 결과 | 뜻 |
|---|---|---|
| 로그 파일 끝 | **널 바이트 1621개** | 파일을 쓰던 도중 전원이 끊김 |
| 프로그램 종료 기록 | 없음 | 프로그램이 죽은 게 아님 |
| 그 시간대 시스템 기록 | **통째로 없음** | 기록을 저장할 새도 없이 꺼짐 |

세 가지가 같은 곳을 가리킨다. **소프트웨어가 아니라 전원이다.** 8/9에 있었던 일과 똑같은 패턴이다.

프로그램이 죽으면 흔적이 남는다. 전원이 나가면 흔적이 남을 시간조차 없어서 **"기록이 없다"는 것 자체가 증거**가 된다.

원인은 아직 모른다. 보조배터리가 순간적으로 차단됐거나, 걸으면서 케이블이 흔들렸을 수 있다.

## 걸린 것 2 — 거리 센서가 "6cm 앞에 뭐가 있다"고 했다

경보 기록에 `obstacle_6cm`, `car_5cm` 같은 게 있었다. 그 순간 사진을 열어봤다.

트인 산책로였다. **6cm 앞에는 아무것도 없었다.**

전체 측정의 **13.8%가 10cm 미만**이었다. 걷는 사람 코앞 10cm에 뭔가가 계속 있을 수는 없다.

### 시간을 보니 규칙이 있었다

| 시각 | 10cm 미만 | 화면 밝기 |
|---|---|---|
| 18:34~18:39 | 거의 없음 | 33~82 |
| 18:44~18:46 | 8 → 18 → 10회 | 63 → 28 → 46 |
| **18:47** | **34회** | **5** |
| 18:48 | 16회 | 8 |

**어두워질수록 헛것이 늘었다.** 둘이 같이 움직인다.

이상한 건, 거리 센서는 적외선을 직접 쏘는 방식이라 어두운 것과 상관이 없어야 한다는 점이다. 그래서 "어두워서 센서가 나빠졌다"가 아니라 **둘 다 망가뜨리는 뭔가가 따로 있다**고 보는 게 맞다. 렌즈 앞에 김이 서렸거나, 기기가 흘러내려 옷에 닿았을 가능성이 있다.

다만 확실하지 않다. 두 번째 세션에서는 같은 값이 **1.9%밖에** 안 나왔다. 같은 기기, 같은 설정, 7분 간격인데 13.8% → 1.9%다. 기기 설정 문제가 아니라 **그때의 물리적 상태** 문제라는 뜻이다.

## 얻은 것 1 — 색 보정은 잘 됐다

지난번에 고친 마젠타(자주색) 끼는 문제는 **야외에서도 재발하지 않았다.** 사진 색이 정상이다.

다만 녹색기는 아직 조금 남아 있다. 보도블록이 살짝 초록빛이다.

## 얻은 것 2 — 경보는 줄었지만, 아직 멀었다

경보를 그냥 세면 조건이 달라서 비교가 안 된다. 오늘은 8/4보다 장애물에 훨씬 가까이 다녔다(위험 상태 시간이 5배). 그래서 **"위험한 상황 1초당 몇 번 말했나"**로 맞춰서 비교했다.

| | 위험 1초당 발화 |
|---|---|
| 8/4 (리마인더 켜짐) | 2.25회 |
| 오늘 세션 1 | 1.51회 |
| 오늘 세션 2 | 0.53회 |

**방향은 맞다.** 같은 위험 상황에서 덜 말한다.

그래도 목표(분당 1회)에는 한참 못 미친다. 오늘은 분당 8.05회였다.

## 그리고 — 조도 조건이 안 맞았다

이게 오늘 데이터의 가장 큰 한계다.

| | 8/4 낮 | 오늘 |
|---|---|---|
| 평균 밝기 | 107 | 47 / 36 |
| 깜깜한 프레임 | 1.1% | **34.9%** |
| 카메라 설정 | — | **노출·감도 둘 다 최대치** |

마지막 줄이 결정적이다. 카메라가 **밝기를 끌어올릴 수단을 전부 다 쓰고도** 어두웠다. 빛 자체가 모자랐다는 뜻이다.

18:34에 출발했는데, 울창한 나무 그늘의 산책로였다. 해가 지기 전이어도 그늘 밑은 이미 밤에 가까웠다.

그래서 오늘 데이터는 **"낮 보행"이라고 부를 수 없다.** 두 번째 세션은 화면에서 아무것도 못 찾은 비율이 97.3%였다.
