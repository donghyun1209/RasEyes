## 들어가기 전에 — "절전 모드"가 뭔가

이 기기는 배터리로 돌아간다. 그래서 **앞에 아무것도 없을 때는 카메라를 늦춘다.**

| | 카메라 속도 |
|---|---|
| 평소 | 초당 15장 |
| **앞이 비었을 때 (절전)** | **초당 4장** |

뭔가 가까이 나타나면 다시 15장으로 올린다. 아무것도 없는 허공을 초당 15장씩 볼 이유가 없으니까.

**여기까지는 의도한 대로다.** 문제는 이게 **1초에 몇 번씩 켜졌다 꺼졌다** 하고 있었다는 것이다.

## 범인을 찾았다 — 절전 모드가 쉴 새 없이 깜빡인다

### 먼저, 야외에서 이상한 걸 봤다

기록을 보면 이렇다.

```
16:41:21  물체 없음 → 절전 켜기 (초당 4장)
16:41:21  84cm에 물체! → 절전 끄기 (초당 15장)
16:41:22  물체 없음 → 절전 켜기
16:41:23  53cm에 물체! → 절전 끄기
16:41:24  물체 없음 → 절전 켜기
16:41:24  24cm에 물체! → 절전 끄기
```

**11분 동안 51번 켜지고 50번 꺼졌다.**

### 왜 이러는가 — 문턱이 있는데 매번 뛰어넘는다

사실 이런 깜빡임을 막는 장치는 **이미 들어가 있었다.**

* 켜는 기준: 물체가 **200cm보다 멀 때**
* 끄는 기준: 물체가 **150cm보다 가까울 때**
* **그 사이 150~200cm에서는 아무것도 안 한다**

에어컨이 26도에서 켜지고 24도에서 꺼지는 것과 같다. 25도 근처에서 껐다 켰다 하지 말라고 **일부러 벌려둔 구간**이다.

그런데 이 구간이 아무 역할을 못 하고 있었다. **거리 센서가 내놓는 값이 그 사이를 지나가지 않기 때문이다.**

여기서 알아야 할 게 하나 있다. **거리 센서는 "못 쟀다"고 할 때 400cm라는 숫자를 대신 내놓는다.** 진짜로 400cm 앞에 뭐가 있다는 뜻이 아니라, **"모름"이라는 표시**다.

그래서 실제로 들어오는 값은 이렇다.

```
트인 곳     → 400cm ("모름" 표시)
뭔가 스침   → 40cm  (실제 측정)
다시 트임   → 400cm
```

**400과 40 사이만 오간다.** 150~200 구간에 값이 들어오는 일이 없으니, 벌려둔 문턱이 통째로 무용지물이다. 매번 훌쩍 뛰어넘는다.

## 오늘 만든 것 — 절전 모드 수정

밝기를 볼 때나 카메라 속도를 볼 때는 **문턱 + "몇 번 연속으로 그래야 인정"** 두 겹을 걸어두고 있었다. 그런데 **절전 모드에는 두 번째가 빠져 있었다.** 두 가지를 넣었다.

| 넣은 것 | 내용 |
|---|---|
| **연속 8번 확인** | 앞이 비었다는 게 8번 **연속으로** 나와야 절전에 들어간다 (약 0.5초) |
| **둘러보기 중에는 절전 끄기** | 돌아보는 동안에는 아예 못 들어가고, **이미 들어가 있었으면 즉시 나온다** |

### 판단이 갈렸던 지점 두 개

**하나 — "들어갈 때만" 까다롭게 했다.**

나올 때도 8번을 기다리게 하면 어떻게 될까? 절전 중에는 한 번이 0.25초라, **물체가 나타나도 2초 뒤에야 반응한다.**

장애물을 알려주는 기기가 2초 늦게 반응하는 건 말이 안 된다. 그래서 **나오는 건 즉시 반응하도록** 했다.

**둘 — 둘러보기는 "막는 것"만으로 부족했다.**

처음엔 "돌아보는 중에는 절전에 못 들어가게" 하면 될 줄 알았다. 그런데 문제의 1회차가 정확히 **이미 들어가 있는 상태로 돌기 시작한** 경우였다. 못 들어가게 막아봐야, 이미 들어가 있으면 소용이 없다.

그래서 **이미 들어가 있으면 나오게** 하는 것까지 넣었다.
